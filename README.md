# Proyecto 2 - Gestor de Tareas en Python

## Descripción
Aplicación de consola desarrollada en Python que permite crear, consultar,
completar y eliminar tareas.

## Problema que resuelve
Ayuda al usuario a organizar tareas pendientes desde una aplicación sencilla
y guardar la información para conservarla entre ejecuciones.

## Tecnologías utilizadas
- Python 3
- JSON para guardar las tareas

## Cómo instalar y ejecutar
1. Instalar Python 3.
2. Descargar o clonar este repositorio.
3. Abrir una terminal dentro de la carpeta del proyecto.
4. Ejecutar:

```bash
python gestor_tareas.py
```

En algunos equipos puede ser necesario usar:

```bash
python3 gestor_tareas.py
```

## Funciones
- Ver tareas.
- Agregar tareas.
- Completar tareas.
- Eliminar tareas.
- Guardar las tareas automáticamente en `tareas.json`.
